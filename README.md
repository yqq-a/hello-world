# Hello World 🌍

这是一个简单的 Hello World 项目，用多种语言向世界问好！

## 项目特色

- 📝 使用 Python 编写的 Hello World 程序
- 🌐 支持多语言输出（中文、英文、日文、西班牙文）
- 🚀 简洁易懂的代码结构
- 📚 完整的使用说明

## 运行方法

确保你的系统已安装 Python 3，然后执行：

```bash
python3 hello.py
```

或者如果你在 Windows 上：

```bash
python hello.py
```

## 预期输出

程序将输出以下内容：

```
Hello, World! 🌍
你好，世界！
こんにちは世界！
¡Hola Mundo!
```

## 文件说明

- `hello.py` - 主程序文件，包含问候语的实现
- `README.md` - 项目说明文档（本文件）

## 开发环境

- Python 3.x
- 支持 UTF-8 编码的终端
